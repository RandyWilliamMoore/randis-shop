Long-form player built in

Plays the current song for as long as you like, slowly changing so it never sounds stuck on repeat. Good for 1-hour and 10-hour videos, sleep and study streams.

To make a 10-hour file: render a seamless loop (Music tab), then loop it with free ffmpeg:
ffmpeg -stream_loop -1 -i loop.wav -t 10:00:00 -c:a libmp3lame -b:a 192k 10hours.mp3

For a 10-hour video with a still background (Video tab → Still image):
ffmpeg -loop 1 -i background.png -stream_loop -1 -i loop.wav -t 10:00:00 -c:v libx264 -tune stillimage -r 2 -c:a aac -b:a 192k 10hours.mp4

Voice cloning needs external model

Cloning a voice needs a trained neural model (gigabytes; a graphics card helps). None is connected, so this is off.

Free open-source options:
• XTTS-v2: https://github.com/idiap/coqui-ai-TTS
• RVC voice conversion: https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI
• OpenVoice: https://github.com/myshell-ai/OpenVoice
• Piper (fast offline TTS): https://github.com/rhasspy/piper

Only clone voices you own or have written permission to use.
