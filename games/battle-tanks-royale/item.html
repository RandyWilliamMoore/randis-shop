🌐 Play a friend over the internet

You both need Battle Tanks Royale open. One of you hosts and gets a private invite code; the other types it in. That's it.

  1. Send this invite code to your friend, privately (a text or a call):
  2. Wait here. You link up as soon as they type it in.
  1. Type or paste your friend's invite code:

Online controls: W/S/A/D or arrow keys to drive, Space or Enter to fire, T to chat. The host is blue (bottom base), the guest is red (top base). 🔒 Everything is sealed end to end with AES-256 using a key made from the invite code. Randis UDS carries the sealed messages through a public relay server, which can see that two computers are talking but can't read the game or the chat. Anyone with the code can join, so only share it with your friend, and host again for a fresh code each time.

⌨ Same keyboard

Player 1: W/S/A/D, Space to fire.   Player 2: Arrow keys, Enter to fire.
Destroy the other base to win. Fair fight: both tanks have the same stats.
